# Yoga Studio Manager 🧘‍♀️

A simple console application for managing yoga classes and reservations, written in Java.

🚧 **Work in progress** – I am developing this project while improving my Java skills.

## Current features

- Display available yoga classes
- Create a reservation for a selected class
- Check available class capacity
- Display registered participants
- Prevent reservations when a class is full

## Technologies

- Java
- Maven
- Git

## Project structure

The application currently consists of:

- `Lekce` – represents a yoga class and handles its reservation logic
- `Main` – provides the console user interface and application flow

## Planned features

- Input validation
- Reservation cancellation
- Separate client and reservation entities
- Date and time management
- Persistent data storage

## About the project

Yoga Studio Manager is my personal Java learning project inspired by my experience as a yoga instructor.

The goal is to gradually develop the application while applying object-oriented programming principles and good coding practices.
